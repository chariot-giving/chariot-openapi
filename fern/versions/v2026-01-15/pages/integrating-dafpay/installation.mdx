Use the supported JavaScript bundle or React package and initialize it with the Connect ID stored for the current nonprofit.

```html
<script src="https://cdn.givechariot.com/chariot-connect.umd.js"></script>
<chariot-connect id="chariot" cid="NONPROFIT_CONNECT_ID"></chariot-connect>
```

The Connect ID is safe in browser code. The API key is not; keep it on your server.

## Prevent tenant mix-ups

Resolve the Connect ID from the same nonprofit record used to render the form. Do not store it in process-wide mutable state, reuse a last-seen value, or fall back to a platform default.

## Placement and styling

Show DAFpay alongside other primary payment methods. Place it before donor fields when using Express Checkout. Use only the supported themes and customization properties; do not target internal component markup.
