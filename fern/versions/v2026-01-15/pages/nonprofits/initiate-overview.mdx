This section is for nonprofits that built and run their own donation form and have to capture each gift from their own backend.

If a fundraising platform hosts your form, stop here. Turn DAFpay on with your platform instead, since they already built this integration. [Find your platform](https://www.givechariot.com/dafpay-setup#integration-search). The same goes for the no-code DAFpay component: gifts reach Chariot on their own.

The Grants API initiates the gift. Everything after that is [Retrieve Donations](/guides/nonprofits/donations).

## What you need

Your dashboard API key already covers grants and donations, so you don't need a second one.

You do need a **connect**, your configured instance of DAFpay, which produces the Connect ID (CID) that initializes the button.

## The order of work

<Steps>

### Request your connect

Chariot creates connects. [Make your configuration choices](/guides/nonprofits/initiate/connect-config) and we set up sandbox and production together.

### Install the button

[Add the component](/guides/nonprofits/initiate/install) to your form with your CID on it.

### Send donor data

[Return what you know about the donor](/guides/nonprofits/initiate/donor-data) so DAFpay can skip those fields.

### Handle the result

[Listen for the events](/guides/nonprofits/initiate/events) the window fires.

### Create the grant

[Call Create Grant](/guides/nonprofits/initiate/create-grant) within 15 minutes. Without this call there is no gift.

</Steps>
