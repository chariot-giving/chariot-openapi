## Webhooks are not arriving

<Steps>

### Confirm you subscribed to a donation event

`grant.created` only fires when a gift is initiated through your own donation form. If you're waiting for a gift record and only subscribed to grant events, nothing will arrive.

### Confirm the key came from this environment's dashboard

Keys you generate cover both grant and donation events. A key issued some other way may be scoped to grants only, and a donation subscription then shows zero deliveries with no error.

### Confirm you have one key for this environment

With more than one, delivery can resolve to the wrong key and events look like they disappeared.

### Check List Events

<EndpointRequestSnippet endpoint="GET /v1/events" />

If the event is listed but never arrived, it's a delivery problem. If it isn't listed, it never fired.

</Steps>

Sandbox never retries a failed delivery, so a handler that was briefly down misses the event outright.

## A checkout looked successful but there is no grant

Call [List Grants](/api/grants/list). An empty list means Create Grant was never called. Receiving `CHARIOT_SUCCESS` does not create a grant.

## One checkout produced two grants

You're initializing with a component connect's CID rather than your API connect's. The window submits the grant and so does your backend.

The no-code component has no backend, so it submits from the modal itself. Contact us if you're not sure which CID you hold.

## A grant has no donation ID

The donation is created asynchronously, so `donationId` isn't on the Create Grant response and isn't always there the first time you call [Get Grant](/api/grants/get). Retry with a short backoff. Don't fall back to matching on the DAFpay tracking ID; about 8% of grants don't have one.

## A donation never settles

This is expected in sandbox, where settlement can't be triggered at all. Test your reconciliation handler against a payload you build yourself, then confirm it in production with one small live gift. We'll run that test with you.

## Still stuck

Send us the environment, your organization name, the endpoint URL you registered, the event categories you subscribed to, and a grant or donation ID you expected an event for: [support@givechariot.com](mailto:support@givechariot.com).
