| Event | Fires when | Metadata |
|---|---|---|
| `CHARIOT_INIT` | The Chariot Connect script is initialized and ready to run. | None |
| `CHARIOT_SUCCESS` | The donor finished. Carries the session id and the grant intent. | `OnSuccessMetadata` |
| `CHARIOT_EXIT` | The donor left without completing, an error occurred, or the donor confirmed an unintegrated grant. | `OnExitMetadata` |

```json onSuccessMetadata
    "workflowSessionId":"79e772be-547d-4c9c-8b76-4ac4ed4c441a", //Id of the Connect session
    "grantIntent": {
      "userFriendlyId": "100020", //The user-friendly identifier for the grant intent
      "fundId": "bbf485dd-a056-4a9d-89a8-06e201cdbf7f", //Id of the donor advised fund
      "amount": 2000, //The grant amount expressed in units of cents; USD only
      "metadata": {} // The same metadata object that was passed in onDonationRequest
    }
  }
```
```json onExitMetadata
  {
    "workflowSessionId": "79e772be-547d-4c9c-8b76-4ac4ed4c441a", // Id of the Connect workflow session.
    "nodeId": "consent-node-id", // The id representing the pane where the donor exited.
    "fundId": "bbf485dd-a056-4a9d-89a8-06e201cdbf7f", // The id of the donor advised fund that was selected.
    "reason": "USER_EXIT", // An enum giving a reason to why the modal exited.
    "description": "User exited the flow" // A human readable string explaining the exit reason.
  }
```
</CodeBlocks>

`CHARIOT_SUCCESS` is where you [create the grant](/guides/nonprofits/initiate/create-grant). On its own it does not create a gift.

## Exit reasons

| Exit Reason | Description |
|---|---|
| `USER_EXIT` | Donor exited the flow. |
| `UNINTEGRATED_DAF` | DAF is not integrated with Chariot. |
| `UNINTEGRATED_GRANT_CONFIRMED` | Unintegrated grant confirmed with Chariot. |
| `CID_NOT_FOUND` | Connect Identifier is not found. |
| `INELIGIBLE_ORGANIZATION` | This organization is not eligible to receive DAF donations. |
| `CREDENTIALS_ERROR` | Invalid credentials. |
| `INVALID_CARD` | Invalid card number. |
| `TFA_ERROR` | Two-factor authentication error. |
| `ZERO_AMOUNT` | Grant amount is zero. |
| `SERVICE_DEACTIVATED` | The connect is deactivated (active = false). |
| `ACCESS_RESTRICTED` | Donor's DAF sponsor account electronic access is restricted. |
| `EIN_NOT_FOUND` | DAF sponsor does not support grants to the organization. |
| `CONNECTION_FAILED` | Connection to the DAF sponsor failed. |
| `SESSION_NOT_FOUND` | Session is not found and may have expired. |
| `CUSTOM_ERROR` | Custom error. |
| `INTERNAL_ERROR` | Internal error. |
| `INSTITUTION_DOWN_ERROR` | DAF sponsor institution is down; the donor should try again later. |
| `NO_CHARITABLE_ACCOUNTS` | Donor has no charitable accounts in the account they logged in to. |
| `INVALID_PRESELECTED_DAF` | Preselected DAF is invalid. |
| `INACTIVE_CARD` | Inactive card. |
| `RECURRING_NOT_SUPPORTED` | Recurring grants are not supported by this DAF. |
| `UNINTEGRATED_DAF_NOT_SUPPORTED` | Unintegrated DAF is not supported by DAFpay. |

`UNINTEGRATED_GRANT_CONFIRMED` is not a failure. It means the donor's provider isn't connected to DAFpay and they confirmed their intent anyway. See [donors on an unconnected provider](/guides/nonprofits/initiate/create-grant#donors-on-an-unconnected-provider).

## When the amount changes mid-session

The amount you passed in can change inside the window. If the donor asks for more than their fund balance, Connect tells them and suggests the balance instead, and if their provider has a minimum, Connect suggests that.

Always record the amount from `CHARIOT_SUCCESS`, never the one from your form.

## Between the window closing and your confirmation page

There's a gap while your backend calls Create Grant. Show a loading screen from `CHARIOT_SUCCESS` until that call returns, and tell the donor not to navigate away — without one they refresh, and that goes badly.

<Frame caption="Loading screen example">
    <img src='../../images/dafpay_form_click.png' />
    <img src='../../images/dafpay_loading_screen.png' />
</Frame>

Two things to get right on the page itself:

**Don't say the gift is being processed.** DAFpay submits a grant request. The donor's provider decides on it and sends the money, usually one to two weeks later.

**Don't promise a tax receipt.** The donor took their deduction when they funded their DAF.

If you accept gifts from donors on an unconnected provider, the page carries more: see [Create the Grant](/guides/nonprofits/initiate/create-grant#donors-on-an-unconnected-provider).
