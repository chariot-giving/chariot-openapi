## Install the package

The button is a small JavaScript package. Load it from the Chariot CDN, or install it from [NPM](https://www.npmjs.com/package/react-chariot-connect) or Yarn.

<CodeBlocks>
```html CDN
<script src="https://cdn.givechariot.com/chariot-connect.umd.js"></script>
```
```shell NPM
npm install --save react-chariot-connect
```
```shell Yarn
yarn add react-chariot-connect
```
</CodeBlocks>

<Warning title="Load the CDN script directly">
If you use the CDN, the script has to come from `https://cdn.givechariot.com` at runtime. Bundling it or hosting a copy yourself breaks it.
</Warning>

## Add the component

Put the component where you want the button to appear, with your Connect ID (CID) on it.

<CodeBlocks>
```html HTML
<chariot-connect id="chariot" cid="GENERATED_CONNECT_IDENTIFIER"></chariot-connect>
```
```javascript React
import React from 'react';
import ChariotConnect from 'react-chariot-connect';

const App = () => {
    return (
        <div>
            <ChariotConnect
                cid="GENERATED_CONNECT_IDENTIFIER"
            />
        </div>
    );
};
```
</CodeBlocks>

We give you the CID when we create your connect, and it doesn't change, so store it rather than fetching it. Sandbox and production have separate CIDs, and the sandbox ones are prefixed `test_`.

<Tip title="Sandbox credentials">

```

```
</Tip>

## Where to put the button

List DAFpay alongside your primary payment methods, next to credit card, bank transfer and Apple Pay. Put it at the top of the form, after currency and one-time versus monthly, and above the gift amount.

Prefill only works when the button comes before your contact fields, and when you pass no `amount`, DAFpay recommends one from the donor's fund balance, which tends to drive larger gifts.

## Themes

Add a theme name to the component. Without one you get `DefaultTheme`.

<CodeBlocks>
```html HTML
<chariot-connect
	id="chariot"
	cid="GENERATED_CONNECT_IDENTIFIER"
	theme="THEME_NAME"
>
</chariot-connect>
```
```javascript React
<ChariotConnect
  cid="GENERATED_CONNECT_IDENTIFIER"
  theme="THEME_NAME"
  ...
/>
```
</CodeBlocks>

For a custom theme, register an object with the properties you want to change, using [Tailwind CSS](https://tailwindcss.com/) values.

<CodeBlocks>
```javascript JavaScript
const chariot = document.getElementById("chariot")

const alterations = {
	width: "w-12",
	height: "h-8",
};

chariot.registerTheme("myTheme", alterations);
```
```javascript React
<ChariotConnect
  cid="GENERATED_CONNECT_IDENTIFIER"
  theme={
        width: "w-12",
        height: "h-8",
    }
  ...
/>
```
</CodeBlocks>

| Parameter Name     | Use                                                         | Allowed value                                                                             |
| :----------------- | :---------------------------------------------------------- | :---------------------------------------------------------------------------------------- |
| `width`            | The width of the button                                     | [width](https://tailwindcss.com/docs/width) up to `16` or `64px`                          |
| `height`           | The height of the button                                    | [height](https://tailwindcss.com/docs/height) at least `9` or `36px` up to `12` or `48px` |
| `showExtendedText` | Show the longer button text, `Give with Donor Advised Fund` | `true` or `false` (`false` by default)                                                    |

The rest of the styling is fixed. Allowing more would mean shipping all of Tailwind in the bundle, which would cost every donor load time.
