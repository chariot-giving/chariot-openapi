There are several ways to use Chariot without integrating with our APIs.

<Note>
This section is for nonprofits. If you are a fundraising platform adding DAFpay for the nonprofits you serve, use [Add DAFpay to your fundraising platform](/guides/dafpay/overview) instead. That integration creates a Connect per nonprofit, which this section does not cover.
</Note>

## If a fundraising platform hosts your form

Search the [DAFpay integrations list](https://www.givechariot.com/dafpay-setup#integration-search). If your platform is listed, turn on DAFpay through the platform. You do not need to build the DAFpay integration yourself.

## If you want to add DAFpay to your own webpage

Your Chariot dashboard provides a DAFpay component and a shareable link. These take only a few minutes to set up and work well for a Ways to Give or campaign page.

A dashboard component offers less flexibility than an API integration: it does not receive fields from your donation form or report the result back to your page.

## If you need more control over DAFpay

Integrate DAFpay when your form needs to:

- pass an amount, designation, donor details, or internal metadata into DAFpay;
- receive the result of the DAFpay session; or
- create and track the grant in your own system.

Start with [Initiate DAF gifts](/guides/nonprofits/initiate).

## If you need donation data in your CRM or ERP

Use the Gift Processing API to retrieve donations, regardless of whether they originated through DAFpay, a fundraising platform, a linked DAF provider, workplace giving, or a lockbox.

Start with [Retrieve donations](/guides/nonprofits/donations).

## If you do not need an API integration

Use a custom export template in the Chariot dashboard to format donation data for your CRM or ERP.

An API integration gives you more flexibility when you need to add DAFpay to a form without native support, retrieve donations automatically, or update donation properties after your system processes them.

## Before you begin

If Grant, Donation, and Deposit are new terms, read [the gift lifecycle](/guides/nonprofits) first. Every page in this section assumes them.

Account setup happens in the [Chariot dashboard](https://dashboard.givechariot.com), not through the API. Use the [Help Center](https://help.givechariot.com) to claim and verify your account, connect payment sources, and configure money movement.
