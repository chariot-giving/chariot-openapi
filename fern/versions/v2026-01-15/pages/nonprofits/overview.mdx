Use Chariot's APIs to:

- Add DAFpay to a donation form you own.
- Retrieve donation data for your CRM or ERP.

You can use either API on its own or use both together. Continue to [Do I need to use the APIs?](/guides/nonprofits/start-here) to choose the right setup.

## The gift lifecycle

Chariot uses three data objects to track a gift's lifecycle:

| Record | What it represents |
| --- | --- |
| Grant | The request sent to the donor's DAF provider through DAFpay. Only gifts initiated through DAFpay have a Grant. |
| Donation | Chariot's record of the gift and its donor, amount, coding, and payment status. |
| Deposit | The transfer in which funds arrive. One deposit can contain multiple donations. |

<Warning>
A donor completing DAFpay does not mean the funds have arrived. DAF providers review and send grants on their own timelines.
</Warning>

Gifts that were not initiated through DAFpay do not have a Grant. Once Chariot receives data for one of those gifts, it is represented as a Donation and, when the funds arrive in a Chariot Account, a Deposit.

## Use the dashboard and APIs together

Use the Chariot dashboard to connect payment sources and configure donation coding. Use the API to add DAFpay to a custom form, retrieve donation data, and write processing status back to Chariot.
