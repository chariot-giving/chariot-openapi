Start by setting up your API key. Server-side calls authenticate with it, passed as a bearer token.

```text
Authorization: Bearer <API_KEY>
```

Sandbox and production use separate API keys, separate Connects, and separate data. Sandbox Connect IDs begin with `test_` and production Connect IDs begin with `live_`.

| Environment | Base URL |
| --- | --- |
| Sandbox | `https://sandboxapi.givechariot.com` |
| Production | `https://api.givechariot.com` |

## Where Each Credential Belongs

The Connect ID appears in your page's HTML, because the browser needs it to render DAFpay. The API key must only ever be used from your server. See [Authentication](/api/authentication) for more information.

DAFpay also needs a few sources allowed in your Content Security Policy. Those belong with the script you embed, so they are on [Install DAFpay](/guides/dafpay/accept/install#content-security-policy).
