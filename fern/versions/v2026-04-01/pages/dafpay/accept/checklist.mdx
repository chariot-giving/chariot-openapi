The steps that break the integration, lose money, or lose data if you get them wrong. If you are a fundraising platform offering DAFpay across many nonprofits' forms, also work through [the platform section](#if-you-serve-many-nonprofits).

## Build

- [ ] Keep the API key on your server. The Connect ID belongs in the page; the key never does.
- [ ] Apply the required CSP directives, or the button will not render.
- [ ] Omit donor fields you do not have. An empty string counts as supplied data and blocks the provider from filling it.
- [ ] Save your transaction before calling Create Grant, so a form error never leaves a donor seeing a failure for a gift that was really sent.
- [ ] Call Create Grant within 15 minutes, and make it idempotent on the workflow session.
- [ ] Route recurring intents to Create Recurring Grant, and never retry it on a `409`. That means the Grant already exists.
- [ ] Store the workflow session, Grant, Donation, tracking, and external Grant identifiers. You cannot reconstruct them later.
- [ ] Verify webhook signatures against the raw request body.

## Validate

- [ ] Repeat Create Grant for one workflow session and confirm only one Grant exists.
- [ ] Complete the donor flow on every supported browser, including with popups blocked.
- [ ] Deliver the same event twice and confirm it does not create a second record.
- [ ] Simulate a completed and a canceled Grant and confirm your handlers respond.

## Launch

- [ ] Complete Chariot's production review.
- [ ] Create production event subscriptions. Sandbox subscriptions do not carry over.
- [ ] Complete a live production gift before opening DAFpay to donors.

## If you serve many nonprofits

Every item here exists because one integration serves many Chariot accounts. A nonprofit integrating its own form can skip them.

- [ ] Create one Connect per nonprofit and store it on that nonprofit's record.
- [ ] Load the Connect ID from the same record that owns the form being rendered.
- [ ] Leave DAFpay unavailable when a nonprofit has no enabled Connect.
- [ ] Display Tracking IDs and External Grant IDs on the nonprofit's dashboard, searchable and easy to copy.
- [ ] Test two nonprofits concurrently and confirm each Grant belongs to the intended one.
