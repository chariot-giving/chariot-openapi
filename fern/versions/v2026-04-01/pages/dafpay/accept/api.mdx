Follow this guide to build directly against the DAFpay APIs, whether you are adding DAFpay to one organization's donation form or offering it across forms for many organizations.

## Key Terms

| Term | Definition |
| --- | --- |
| Connect | The DAFpay setup for one organization. Its ID tells Chariot which organization receives the gift. Organizations can have multiple Connects if they receive DAFpay from multiple places online. |
| Workflow session | A single DAFpay session. A new workflow session starts each time a donor clicks the DAFpay button, and you use its ID to create the Grant. |
| Grant | A grant initiated to a DAF provider, created via the [Create Grant](/api/grants/create) endpoint. |
| Donation | A gift recorded in Chariot, available to Chariot Deposit Account holders. Donations come from DAFpay Grants, Chariot disbursement partners, or connected payment sources. [Processing Donations](/guides/dafpay/accept/managing-gifts#processing-donations) covers how a Grant becomes a Donation. |

## How the Integration Works

1. Get the Connect for the organization receiving the gift. Chariot provides it if you are integrating one organization's form. If you serve many, you create one per nonprofit.
2. Render Chariot Connect using that organization's Connect ID.
3. Pass the current form values into DAFpay.
4. Receive `CHARIOT_SUCCESS` and create the Grant from your server within 15 minutes.
5. Store the workflow session, Grant, and reconciliation identifiers.
6. Subscribe to Grant updates.
