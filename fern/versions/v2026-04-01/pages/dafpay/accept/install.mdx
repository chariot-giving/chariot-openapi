Load Chariot Connect and initialize it with the Connect ID stored for the nonprofit whose form the donor is viewing.

```html
<script src="https://cdn.givechariot.com/chariot-connect.umd.js"></script>

<chariot-connect
  id="chariot"
  cid="NONPROFIT_CONNECT_ID"
  theme="LightModeTheme">
</chariot-connect>
```

## Checkout mode

By default, Chariot chooses whether the checkout opens as a modal on your page or in a popup window, based on the donor's browser and where the button is placed. To always use one mode, set the `context` attribute.

<CodeBlocks>
```html HTML
<chariot-connect id="chariot" cid="NONPROFIT_CONNECT_ID" context="popup"></chariot-connect>
```
```javascript React
<ChariotConnect
    cid="NONPROFIT_CONNECT_ID"
    context="popup"
/>
```
</CodeBlocks>

| Value | Behavior |
| --- | --- |
| `iframe` | Opens the checkout as a modal over your page. |
| `popup` | Opens the checkout in a separate browser window. |

<Note>
In `iframe` mode the modal covers the frame the button is rendered in. If the button sits inside an iframe that is taller than the donor's screen, use `popup` or the default. In `popup` mode, follow the guidance in [Prevent blocked popups](/guides/dafpay/accept/donation-data#prevent-blocked-popups).
</Note>

## Prevent tenant mix-ups

Resolve the Connect ID from the same nonprofit record used to render the form. Do not hardcode an ID, store it in process-wide mutable state, reuse the last value loaded, or fall back to a platform default.

If the nonprofit has no enabled Connect, do not render DAFpay. Show the appropriate setup state in the nonprofit's platform settings instead.

## Styling

`theme` is optional. Set it on the `chariot-connect` element to change how the DAFpay button looks.

- `DefaultTheme`
- `LightModeTheme`
- `LightBlueTheme`
- `GradientTheme`

You can also register a custom theme:

```javascript
chariot.registerTheme("myTheme", {
  width: "w-12",
  height: "h-9",
  showExtendedText: true
});
```

| Property | Use | Allowed value |
| --- | --- | --- |
| `width` | Button width | Numeric steps to `w-12`, fractions like `w-1/2`, or keywords like `w-full` |
| `height` | Button height | Numeric steps to `h-12`, or keywords like `h-full` |
| `showExtendedText` | Show the longer button label | `true` or `false` |
