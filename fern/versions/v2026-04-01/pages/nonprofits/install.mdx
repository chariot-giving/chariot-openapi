This covers everything between having your Connect ID and having a working DAFpay button. What happens after a donor finishes in the window is in [Custom Donation Forms](/guides/nonprofits/dafpay).

If DAFpay runs on your fundraising platform rather than a form you built, your platform handles all of this and you don't need this page.

## Install the package

The button is a small JavaScript package. Load it from the Chariot CDN, or install it from [NPM](https://www.npmjs.com/package/react-chariot-connect) or Yarn.

<CodeBlocks>
```html CDN
<script src="https://cdn.givechariot.com/chariot-connect.umd.js"></script>
```
```shell NPM
npm install --save react-chariot-connect
```
```shell Yarn
yarn add react-chariot-connect
```
</CodeBlocks>

<Warning title="Load the CDN script directly">
If you use the CDN, the script has to come from `https://cdn.givechariot.com` at runtime. Bundling it or hosting a copy yourself breaks it.
</Warning>

## Add the component

Put the component where you want the button to appear, with your Connect ID (CID) on it.

<CodeBlocks>
```html HTML
<chariot-connect id="chariot" cid="GENERATED_CONNECT_IDENTIFIER"></chariot-connect>
```
```javascript React
import React from 'react';
import ChariotConnect from 'react-chariot-connect';

const App = () => {
    return (
        <div>
            <ChariotConnect
                cid="GENERATED_CONNECT_IDENTIFIER"
            />
        </div>
    );
};
```
</CodeBlocks>

Chariot gives you the CID when we create your connect, and it doesn't change, so store it rather than fetching it. You get a separate CID for sandbox and for production. [Request your connect](/guides/nonprofits/dafpay/connect-config) if you don't have one yet.

<Tip title="Sandbox credentials">
Use these to log in to any DAF provider in sandbox.

```
username: good-user
password: password123
```
</Tip>

## Where to put the button

List DAFpay directly alongside your primary payment methods, next to credit card, bank transfer and Apple Pay.

Put it at the top of the form: after currency and one-time versus monthly, and above the gift amount. Prefill only works when the button comes before your contact fields, and when you pass no `amount`, DAFpay recommends one from the donor's fund balance, which drives larger gifts.

## Sending donor data

Return the donor's information from `onDonationRequest` and DAFpay skips the fields you provide. Anything you leave out gets filled from the donor's DAF account.

<CodeBlocks>
```javascript JavaScript
const chariot = document.getElementById("chariot")

chariot.onDonationRequest(async () => {
  return {
    amount: 25000, //this is $250.00 USD
    designation: "My Special Designation",
    metadata: {
      fundraiserTag: "marathon"
    },
  }
})
```
```javascript React
const onDonationRequest = () => {
    return {
        amount: 25000, //this is $250.00 USD
        designation: "My Special Designation",
        metadata: {
            fundraiserTag: "marathon"
        },
    }
}

<ChariotConnect
    cid="GENERATED_CONNECT_IDENTIFIER"
    onDonationRequest={onDonationRequest}
/>
```
</CodeBlocks>

<Error title="Empty strings count as provided">
Chariot treats any value you pass as provided, including an empty string. Sending `email: ""` tells us the donor's email is blank, and the donor types it by hand instead of having it prefilled.

To get DAF prefill, omit `firstName`, `lastName`, `email`, `phone` and `address` entirely. Don't send them set to `""`.
</Error>

| Parameter   | Description                                                                                                                                                                                                                                           | Type              |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------|
| amount      | The donation amount in cents. e.g., for a $20 donation, enter 2000.  <br /><br />If this value is not passed in, Chariot will use the donor's account balance to recommend a donation amount. This can lead to significantly larger donation amounts.  | number (optional) |
| firstName   | The donor's first name. Maximum length: 255 characters.                                                                                                                                                                                               | string (optional) |
| lastName    | The donor's last name. Maximum length: 255 characters.                                                                                                                                                                                                | string (optional) |
| email       | The donor's email address. Must be in email format. Maximum length: 255 characters.                                                                                                                                                                   | string (optional) |
| phone       | The donor's phone number. Provide the country code and no special characters. Maximum length: 255 characters.                                                                                                                                         | string (optional) |
| note        | A note the donor wants to send to your organization. Maximum length: 400 characters.                                                                                                                                                                  | string (optional) |
| anonymous   | Indicates if this donation should be sent anonymously (default: false). Pass this when a donor chooses to give anonymously on your form, so the DAF provider anonymizes it properly.                                                                   | boolean (optional)|
| designation | The designation to include on the grant. If this is left blank, "Where needed most" will be used. A custom designation may make the grant approval process take longer. Designations over 100 characters will be truncated. Maximum length: 255 characters. | string (optional) |
| address     | The donor's address: line1, line2, city, state, postalCode. Maximum length: 255 characters.                                                                                                                                                           | object (optional) |
| metadata    | Any name-value pairs you want tied to the session, such as a form ID or campaign name. They come back on the grant intent.                                                                                                                            | object (optional) |
| fundId      | The ID of a preselected DAF provider. <br /><br /> If you provide it, the donor skips the DAF dropdown and goes straight to that provider's login.                                                                                                    | string (optional) |
| frequency   | The recurring frequency of the grant. `ONE_TIME` or `MONTHLY`. Defaults to `ONE_TIME`. See [recurring gifts](/guides/nonprofits/dafpay#recurring-gifts).                                                                                              | string (optional) |

Anything longer than its maximum is truncated rather than rejected.

To hold the button back until your own validation passes, return `false` from `onDonationRequest`.

## Popup timing

Mobile browsers block popups they consider decoupled from the click that asked for one, which happens when something slow runs between the click and the window opening.

<Tip title="Keep it under a second">
- Keep the gap between the donor's click and the popup under 1000ms.
- Don't make blocking API calls before launching the popup.
- Avoid long-running async work anywhere in the donation request flow.
- Prefetch what you need before the donor clicks.
</Tip>

The two ways forms usually break this: a custom button that calls your own server before triggering the popup, and async work inside `onDonationRequest` such as fetching giving history or looking up prefill data. Move that work earlier, before the donor clicks.

## Button themes

Add a theme name to the component. Without one you get `DefaultTheme`.

<CodeBlocks>
```html HTML
<chariot-connect
	id="chariot"
	cid="GENERATED_CONNECT_IDENTIFIER"
	theme="THEME_NAME"
>
</chariot-connect>
```
```javascript React
<ChariotConnect
  cid="GENERATED_CONNECT_IDENTIFIER"
  theme="THEME_NAME"
  ...
```

For a custom theme, register an object with the properties you want to change, using [Tailwind CSS](https://tailwindcss.com/) values.

<CodeBlocks>
```javascript JavaScript
const chariot = document.getElementById("chariot")

const alterations = {
	width: "w-12",
	height: "h-8",
};

chariot.registerTheme("myTheme", alterations);
```
```javascript React
<ChariotConnect
  cid="GENERATED_CONNECT_IDENTIFIER"
  theme={
        width: "w-12",
        height: "h-8",
    }
  ...
/>
```
</CodeBlocks>

| Parameter Name     | Use                                                                                      | Allowed value                                                                             |
| :----------------- | :--------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------- |
| `width`            | The width of the button                                                                  | [width](https://tailwindcss.com/docs/width) up to `16` or `64px`                          |
| `height`           | The height of the button                                                                 | [height](https://tailwindcss.com/docs/height) at least `9` or `36px` up to `12` or `48px` |
| `showExtendedText` | Show the longer button text, `Give with Donor Advised Fund`                              | `true` or `false` (`false` by default)                                                    |

The rest of the button's styling is fixed. Chariot would have to ship all of Tailwind in the bundle to allow more, which would cost every donor the load time.

| Event Name         | Description                                                                                                                                                     | Metadata Type       |
|--------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------|
| `CHARIOT_INIT`     | Fires when the Chariot Connect script is initialized and ready to run.                                                                                          | None                |
| `CHARIOT_SUCCESS`  | A final summary of the Connect session, with the session id and the grant intent. Call [Create Grant](/api/grants/create) or [Create Recurring Grant](/api/recurring-grants/create) when you get it. | `OnSuccessMetadata` |
| `CHARIOT_EXIT`     | Fires when a donor leaves without completing the flow, when an error occurs, or when a donor confirms an unintegrated grant.                                    | `OnExitMetadata`    |

## When the amount changes mid-session

The amount you passed in can change inside the window. If the donor asks for more than their fund balance, Connect tells them and suggests the balance instead, and if their provider has a minimum, Connect suggests that. Always record the amount from `CHARIOT_SUCCESS`.
