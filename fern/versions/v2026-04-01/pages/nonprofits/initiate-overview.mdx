Follow this guide if your organization wants to integrate DAFpay directly into a donation form you own. If your form is hosted by a fundraising platform, enable DAFpay through that platform instead.

<Note>
If you are a fundraising platform that serves many nonprofits, use [Add DAFpay to your fundraising platform](/guides/dafpay/overview) instead.
</Note>

By the end of this section your donation form will open DAFpay, receive the donor's authorization, and create the grant from your server.

## Before you start

Server-side calls in this section need an API key and the base URL for the environment you are working in.

| Environment | Base URL |
| --- | --- |
| Sandbox | `https://sandboxapi.givechariot.com` |
| Production | `https://api.givechariot.com` |

Sandbox and production use separate API keys, and each key works only against its own base URL. See [Authentication](/api/authentication) for how to send the key.

The integration has four parts:

<Steps>

### Get a Connect ID for your form

Chariot configures a Connect for your organization and gives you separate sandbox and production IDs. See [Request your Connect](/guides/nonprofits/initiate/connect-config).

### Add Chariot Connect to the page

Load the script and place the DAFpay button on your form. See [Install the button](/guides/nonprofits/initiate/install).

### Pass donation data into the DAFpay session and handle its events

Return your form's current values so the donor does not retype them, then handle the three events the component emits. See [Send donor data](/guides/nonprofits/initiate/donor-data) and [Handle the result](/guides/nonprofits/initiate/events).

### Create the grant from your server after `CHARIOT_SUCCESS`

The browser flow only authorizes the gift. Your server still has to create it, once, within 15 minutes. See [Create the grant](/guides/nonprofits/initiate/create-grant).

</Steps>

```
Donation form → DAFpay session → CHARIOT_SUCCESS → your server → Create Grant
```

<Warning>
`CHARIOT_SUCCESS` means the donor authorized the request. It does not create the grant and does not mean the nonprofit has received money.
</Warning>
