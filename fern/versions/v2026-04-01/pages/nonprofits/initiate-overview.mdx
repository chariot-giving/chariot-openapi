Follow this section only if your organization owns and operates the donation form. If a fundraising platform hosts your form, check whether it supports DAFpay and enable DAFpay there.

## Before you start

Server-side calls in this section need an API key and the base URL for the environment you are working in.

| Environment | Base URL |
| --- | --- |
| Sandbox | `https://sandboxapi.givechariot.com` |
| Production | `https://api.givechariot.com` |

Sandbox and production use separate API keys, and each key works only against its own base URL. See [Authentication](/api/authentication) for how to send the key.

<Warning>
Never infer the environment from an ID alone. Configure the base URL, API key, and Connect ID together.
</Warning>

The integration has four parts:

<Steps>

### Get a Connect ID for your form

See [Request your Connect](/guides/nonprofits/initiate/connect-config).

### Add Chariot Connect to the page

See [Install the button](/guides/nonprofits/initiate/install).

### Pass donation data into the DAFpay session and handle its events

See [Send donor data](/guides/nonprofits/initiate/donor-data) and [Handle the result](/guides/nonprofits/initiate/events).

### Create the grant from your server after `CHARIOT_SUCCESS`

See [Create the grant](/guides/nonprofits/initiate/create-grant).

</Steps>

```
Donation form → DAFpay session → CHARIOT_SUCCESS → your server → Create Grant
```

<Warning>
`CHARIOT_SUCCESS` means the donor authorized the request. It does not create the grant and does not mean the nonprofit has received money.
</Warning>
