---
title: "Source Connections"
subtitle: "Your organization's persistent link to a source, or a bring-your-own bank address."
---

A **Source Connection** is your organization's persistent relationship with a [Source](../sources/overview), or a bring-your-own bank address you've added directly. Donations and deposits reference source connections by ID.

Source connections come in two shapes:

- **Linked** — points at a canonical Source in Chariot's directory via `source_id`. Fidelity Charitable, Schwab Charitable, Benevity, and every other Chariot-supported payer are represented this way once an organization connects to them.
- **Bring-your-own (BYO)** — has no `source_id`. Carries its own `financial_address` (ACH routing + account numbers) so the organization can receive from a source that isn't in Chariot's directory.

Both shapes share the same endpoints, the same identifier space, and the same CRUD surface. `source_id` is the discriminator.

Use Source Connections when you need to:

- **Attribute a donation to a specific inflow.** Every donation's source connection ID points at the source connection through which the money arrived.
- **Add a bring-your-own bank account.** `POST /v1/source_connections` with a `financial_address` and no `source_id`.
- **Render the "connect a source" screen.** `GET /v1/source_connections?include=available` returns your existing source connections plus a virtual row for every unconnected Source, so the dashboard can render both in one call.
- **Disconnect a source.** `DELETE /v1/source_connections/{id}` removes the source connection. Existing donation and deposit references still resolve; new activity is blocked.

See [The Source Connection object](object) for the full schema.
