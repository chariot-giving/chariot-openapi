## Onboard nonprofits

* [ ] Search for each nonprofit by EIN.
* [ ] Create one Connect per nonprofit on your platform.
* [ ] Store the Connect ID on the corresponding nonprofit record.
* [ ] Define how existing and new nonprofits will be enabled.
* [ ] Use a nonprofit-specific contact email, not your platform support address.
* [ ] Follow the opt-in, default-on, or other enablement rule in your Chariot agreement.
* [ ] Give nonprofits clear setup instructions and the co-branded Chariot signup link supplied for your platform.

## Add DAFpay

* [ ] Load the supported JavaScript or React package.
* [ ] Initialize with the current nonprofit's Connect ID.
* [ ] Keep the API key on your server; never expose it in browser code.
* [ ] Place DAFpay above the form as Express Checkout or next to the primary payment methods.
* [ ] Apply required CSP directives.

## Complete the transaction

* [ ] Return current form data from `onDonationRequest`.
* [ ] Omit unknown donor fields instead of sending empty strings.
* [ ] Handle all Chariot Connect events.
* [ ] Save your transaction before calling Create Grant.
* [ ] Make Create Grant idempotent and complete it within 15 minutes.
* [ ] Route recurring intents to Create Recurring Grant.
* [ ] Implement the configured unsupported-provider behavior.
* [ ] Create the Grant exactly once after `CHARIOT_SUCCESS`.
* [ ] Pass campaign, form, designation, appeal, comment, and tribute data when the form collects it.
* [ ] Use accurate copy for loading, success, exit, unclaimed-account, and missing-EIN states.

## Operate the integration

* [ ] Store workflow session, Grant, and Donation identifiers.
* [ ] Subscribe to grant status events and verify signatures.
* [ ] Expose reconciliation identifiers to support and nonprofit users.
* [ ] Test two nonprofits concurrently in sandbox.
* [ ] Complete Chariot's production review.
* [ ] Decide whether DAFpay gifts sync through each CRM integration and how hard and soft credit are assigned.
* [ ] Give support teams access to the platform transaction ID, Chariot Grant ID, and Donation ID.
* [ ] Document how nonprofits enable DAFpay and whether they enable it once or per form.
* [ ] Plan a production test and post-launch review.
