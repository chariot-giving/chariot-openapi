This guide is for fundraising platforms that want to offer DAFpay to multiple nonprofit customers. If you are a nonprofit adding DAFpay to a form you own, use [Chariot for nonprofits](/guides/nonprofits).

You integrate once, but each nonprofit receives its own Connect. Your platform must load the Connect ID that belongs to the nonprofit whose form the donor is viewing.

```
Nonprofit record → Connect ID → DAFpay session → Grant
```

<Warning>
Never use one platform-wide Connect ID. The Connect identifies the recipient and the source of the gift.
</Warning>

## Integration flow

<Steps>

### Search for the nonprofit

Look the organization up by EIN, so the Connect attaches to the right one. See [Create Connects](/guides/dafpay/integrating-dafpay/connects).

### Create or retrieve its Connect and store the Connect ID

One Connect per nonprofit, created when they turn DAFpay on, stored on their record in your database. See [Create Connects](/guides/dafpay/integrating-dafpay/connects) and [Configure your Connects](/guides/dafpay/integrating-dafpay/connect-config).

### Render Chariot Connect on that nonprofit's form

Load the component with that nonprofit's Connect ID, and allow Chariot's sources in your CSP. See [Install DAFpay](/guides/dafpay/integrating-dafpay/installation) and [Content Security Policy](/guides/dafpay/integrating-dafpay/csp).

### Pass current form data into DAFpay

Return the live form values so the donor does not retype what they already entered. See [Send donation data](/guides/dafpay/integrating-dafpay/donor-data).

### After `CHARIOT_SUCCESS`, create the Grant from your server

The event authorizes the gift; your server creates it, exactly once, within 15 minutes. See [Handle the result](/guides/dafpay/integrating-dafpay/events) and [Create the grant](/guides/dafpay/integrating-dafpay/create-grant).

### Store Chariot identifiers and listen for status changes

Keep the workflow session, Grant and Donation IDs so support and finance can trace a gift later. See [Reconciliation](/guides/dafpay/gifts/reconciliation) and [Grant statuses](/guides/dafpay/gifts/statuses).

</Steps>

Your platform's Connects require your server to create the Grant after the donor completes DAFpay. `CHARIOT_SUCCESS` alone does not create a Grant or mean the nonprofit has received funds.

Start with [Sandbox testing](/guides/dafpay/sandbox). The [Integration checklist](/guides/dafpay/integrating-dafpay/checklist) is the whole job in one page — use it as a roadmap now and work through it before you ask for production access.
